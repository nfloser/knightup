# Puzzle library

Lichess exports its puzzle database under CC0-1.0: https://database.lichess.org/#puzzles . KnightUp includes 4,000 source positions filtered for popularity >=70, rating deviation <=100 and rating 400–2000. The subset is not the full database. `docs/puzzle-source.json` records the compressed prefix hash and source URL. `python scripts/import-puzzles.py` downloads at most 4 MiB; run `npm test` to validate every legal variation before updating the pack. Python requires zstandard. Data files are included in offline precache; no scraping or user token is used.

The first database move belongs to the opponent and is applied before the learner sees the position. The board orients to the learner's color. A puzzle is solved only after the complete supplied variation; opponent replies play automatically. Wrong moves, hints and Explain mark assistance and bring the item back for review. Focused review prioritizes due low-box items within your filters. Random selection avoids repeats within the current filter session where possible. Puzzle difficulty is separate from a playing rating. Explain shows the official line and independent theme explanations; alternative lines are not accepted as engine-equivalent without an engine check.
